For college video assignments (e.g. Pemrograman Web / Sistem Operasi):
- Prefer modular multi-take screen + facecam recording (OBS / screen recorder) split into separate clips.
- Edit, stitch, sync audio, and export using CapCut PC (1080p).
- Always budget a 1.5 - 2 hour dedicated buffer block for CapCut editing, rendering, and YouTube upload.
- Deliverable is uploaded to YouTube (Unlisted/Public) and link submitted to LMS (FLearn/Google Classroom).
