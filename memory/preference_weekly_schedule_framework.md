Misael's framework for realistic weekly scheduling:
1. **Asymmetric Theme Days:** Heavy lecture/asdos days are maintenance-only (classes + <1h light review). Light/empty days are dedicated deep work sprint days.
2. **Deep Work Balance:** 50:50 ratio on sprint days, temporally isolated (morning block for coursework mastery, afternoon/evening block for dedicated Productivity Time / personal projects).
3. **Capacity Buffer:** 70% rule (1.5 - 2 hours unassigned daily buffer) to absorb bugs, delays, and unexpected tasks.
4. **Rest & Recovery:** Sunday is completely off (zero study/work). Saturday is a flexible catch-up buffer + weekly review.
5. **Tooling:** Google Calendar with color-coded time blocks (Classes/Asdos, Coursework, Software Projects, Buffer, Rest).
